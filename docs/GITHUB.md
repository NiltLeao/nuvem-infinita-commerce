# GitHub

## V1.0.1

Antes de publicar:

- mantenha o arquivo `LICENSE` como GPL-2.0-or-later;
- mantenha uma única licença do projeto, consistente com GPL-2.0-or-later;
- confirme que não existem tokens, senhas, chaves ou arquivos `.env`;
- use a tag `v1.0.1` para marcar a versão;
- mantenha os conectores de marketplaces desativados até a validação das APIs e permissões.

O GitHub pode sugerir ou criar uma licença automaticamente. Para este projeto, o arquivo oficial do repositório deve permanecer consistente com GPL-2.0-or-later.
